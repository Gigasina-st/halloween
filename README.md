# عمارت بلک‌وود 🎃\n\nیک تجربه‌ی تعاملی کاملاً فارسی برای هالووین، ویژه‌ی سما. طراحی تمام‌صفحه و بدون اسکرول، روایت چندمرحله‌ای، جامپ‌اسکر و راز پایانی.\n\n## انتشار رایگان\nدر تنظیمات مخزن، بخش Pages را باز کنید؛ گزینه‌ی Deploy from a branch را انتخاب کنید، شاخه‌ی main و پوشه‌ی /(root) را مشخص کنید و ذخیره کنید. پس از انتشار، نشانی سایت در همان بخش نمایش داده می‌شود.\n\nسایت با یک فایل HTML کار می‌کند و به دستور ساخت یا بک‌اند نیاز ندارد.
